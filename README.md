# UNAD - Programación (Código 213023)
## Fase 2 - Sistema para Control de Lavado (Ejercicio 3)

### 📌 Descripción
Este proyecto consiste en una aplicación de escritorio desarrollada en Python con Tkinter que implementa un módulo de inicio de sesión con POO y un sistema para el control de entrada, tiempo de permanencia y cobro en un autolavado.

### 🛠️ Tecnologías y Conceptos Aplicados
- **Lenguaje:** Python 3
- **GUI:** Tkinter (en idioma inglés)
- **Paradigma:** Programación Orientada a Objetos (POO)
- **Encapsulamiento:** Atributos privados (`_usuario`, `_password`, `_placa`, `_hora_ingreso`, `_tarifa_hora`)
